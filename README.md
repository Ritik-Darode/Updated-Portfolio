## ✨ Key Features

* **🎨 Algorithmic Art Engine**: Interactive HTML5 `<canvas>` particle simulation class with dynamic wave motion, mouse physics (attraction/repulsion), and 6 switchable mood presets (`neutral`, `confident`, `creative`, `intense`, `calm`, `joy`).
* **🌊 Lenis Inertial Smooth Scroll**: Apple-grade smooth scrolling experience across all screen sizes.
* **🎬 GSAP + ScrollTrigger Stagger Reveals**: Scroll-driven reveal animations for section titles, project cards, and timelines.
* **🎴 3D Perspective Mouse Tilt**: Interactive perspective tilt effect on project and skill cards.
* **💎 Dark Cyber-Glass Design System**: High-contrast frosted glass cards (`backdrop-filter: blur`), glowing neon accents (`#00ff96` & `#00d4ff`), and custom gradient scrollbar.
* **🎉 Interactive Confetti Triggers**: Interactive celebratory particle bursts on action button clicks.
* **📱 Fully Responsive Layout**: Mobile drawer navigation, adaptive timeline, and responsive project grids.

## 💻 Local Development Setup

To run and view this project locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ritik-Darode/Updated-Portfolio.git
   cd Updated-Portfolio
   ```

2. **Serve the project using Python or HTTP server**:
   ```bash
   # Option A: Using Python built-in server
   python -m http.server 8000

   # Option B: Using Node http-server
   npx http-server -p 8000
   ```

3. **Open in Browser**:
   Navigate to `http://localhost:8000`

## 🚀 Deployment to GitHub Pages

This project is configured for one-click deployment via GitHub Pages:

1. Push your changes to the `main` branch:
   ```bash
   git add .
   git commit -m "Update portfolio features"
   git push origin main
   ```
2. In GitHub repository settings:
   * Go to **Settings** ➔ **Pages**
   * Select `main` branch and `/ (root)` directory
   * Save and wait for GitHub Actions build to deploy automatically.
